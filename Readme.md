### LeetCode AI Helper 🚀

An AI-powered Chrome extension that helps users solve LeetCode problems using **Google Gemini AI**.

**Key Features**

* AI-powered, context-aware hints
* Multiple solution approaches and step-by-step guidance
* Code debugging assistance
* Natural-language conversation
* Automatic LeetCode problem detection
* Progress tracking and personalized learning
* Fallback responses and error handling

**Tech Stack:** Chrome Extension, JavaScript, Next.js, Gemini AI API, JWT, Database

**How It Works:**
The extension captures the user's question and current problem context, sends it to the backend, and uses Gemini AI to generate a personalized response.

**Impact:**
Replaces static responses with dynamic AI assistance, making problem-solving more interactive, personalized, and adaptive.
